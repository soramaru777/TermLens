# raw/ — 不変のソース置き場

ここには**加工前の一次資料**を置く。仕様書、議事録、調査メモ、参考記事のクリップ、外部ドキュメントなど。

## このディレクトリは git 追跡しない

**`docs/raw/` の中身はローカル限定**で、この `README.md` だけが追跡される（`.gitignore` 参照）。

理由は、加工前のセッション記録や議事録には **API キーや個人情報が混ざりやすい**うえ、一度コミットすると `git rm` しても**履歴からは消えない**ため。将来このリポジトリを公開する可能性がある以上、「後から消せる」前提では設計しない。

要約・構造化された知識は `docs/wiki/` に入り、そちらは追跡される。**LLM が要約する過程が実質的なフィルタになる**ので、共有すべき内容は wiki 側に残る。

そのため、**Issue・PR・コミットメッセージで `docs/raw/` のファイル名に言及しない**こと。

## ルール

- **一度置いたファイルは書き換えない。** 内容が変わったら日付付きの新しいファイルとして追加する
- LLM はここを**読むだけ**。編集・削除しない
- API キーや認証情報を含むファイルは置かない（追跡していなくても、事故の温床になるため）
- ファイル名は `YYYY-MM-DD-topic.md` 形式を推奨

## 取り込み方

Claude Code で `/llm-wiki ingest docs/raw/<file>` を実行すると、`docs/wiki/` の該当ページが更新され、`index.md` と `log.md` に記録される。

## 取り込み済みソースの記録

取り込んだ資料は各 wiki ページの frontmatter `sources:` に記録される。**実体がローカルにしか無いファイルも出典として名前は残す**（provenance の記録として意味があるため）。
