# raw/ — 不変のソース置き場

ここには**加工前の一次資料**を置く。仕様書、議事録、調査メモ、参考記事のクリップ、外部ドキュメントなど。

## ルール

- **一度置いたファイルは書き換えない。** 内容が変わったら日付付きの新しいファイルとして追加する
- LLM はここを**読むだけ**。編集・削除しない
- API キーや認証情報を含むファイルは置かない
- ファイル名は `YYYY-MM-DD-topic.md` 形式を推奨

## 取り込み方

Claude Code で `/llm-wiki ingest docs/raw/<file>` を実行すると、`docs/wiki/` の該当ページが更新され、`index.md` と `log.md` に記録される。

| ハンドオフメモ | `docs/local/status-2026-08-13.md`（git 未追跡のためここには複製しない） | 2026-08-13 |
